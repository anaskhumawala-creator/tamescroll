How it works
01

Type your platforms

You name what you already use. tamescroll never lists or suggests one — a platform you don't type simply doesn't exist here.

02

Everything starts hidden

Ads, promoted posts, Shorts, Reels, For You, trending, autoplay — gone by default. The ads never come back; there is no setting for them.

03

Bring back what you choose

Comments, subscriptions, search — each surface has one plain toggle, per platform. Nothing returns unless you turn it on.

Cleaned platforms

Each platform opens as itself, minus what it uses to hold you. You add only the platforms you already use — tamescroll never suggests another.

On-device privacy

Image blur and keyword filters run on your device. No account, no telemetry, no server of ours in the middle. What you read and watch stays yours.

Free and open source

MPL-2.0-licensed, built in the open. Read the code, file an issue, or build it yourself. There is nothing to buy and nothing to subscribe to.

The platforms stay useful. The pull is gone.
