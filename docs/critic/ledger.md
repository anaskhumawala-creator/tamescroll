# Critic ledger

Every finding filed by a critic run lands here as one row, verdict `OPEN`.
A row closes only with an artifact, never with an argument
(`docs/critic-loop.md` §7):

- `CONFIRMED` — a commit that fixes it, plus a check red before and green after.
- `REFUTED` — the falsifier was **run**, and its raw output is pasted into the row.
- `ACCEPTED-COST` — cite the `docs/engine-findings.md` §9 line that makes this a cost.

`bench/critic-gate.mjs` exits non-zero while any `EXPOSURE` or `WRONG-NUMBER` row
is `OPEN`.
