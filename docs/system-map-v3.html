01

The product — three pieces, one core

Deliberately narrow: the app is not a general browser and never competes with Chrome or Brave. General browsing stays in the user's own browser, covered by extensions.

★ flagship · mobile

Clean Feeds App

Opens only the five platforms in cleaned web views. No address bar. Nowhere to wander.

  • Thin shell on the OS engine (WebView / WKWebView) — no engine fork, no Kiwi trap
  • Script injection cleans what iOS content blockers can't (same-origin YouTube ads)
  • Native autofill: Keychain / Google PM / passkeys — sign-in once, gracefully (no microG-style jank)
  • No in-app kill switch — blocking can't be toggled off in two taps at 1am
sibling · desktop

Extension

Standard Web Extension, one codebase.

  • Chrome · Brave · Edge · Firefox
  • Firefox on Android accepts it near-free
  • Apple's converter → Safari/iOS version
  • Pairs with existing tools (HaramBlur, uBlock) for general browsing
first-class · paper

The Playbook

The missing manual nobody has written.

  • Plain language a parent can follow
  • Install → lock → hand the passcode to someone who loves you
  • Home-screen icons that look like the real apps
📄
core · instant · always on

Block rules + CSS (EasyList model)

Ads, Shorts/feeds, thumbnail blur-all, nag-strip. Plain text, decoupled from the shells — fixes reach everyone with no app update. Zero lag.

🧠
module · on-device · phase 2

AI gaze protection

Frame-by-frame blur inside videos (HaramBlur lineage, open bases). Three modes set once: explicit only · + opposite gender (either direction) · strictest (all people). Never in the critical path.

02

Bypass resistance — three rings

Designed for the 1am relapse, not the motivated Monday morning. Each ring costs more to break than the last.

ring 1 · inside the app

Clean by construction

The rules are baked in. There is no settings toggle staring at the user, nothing to disable in two taps.

ring 2 · on the phone

OS lock pairing

Screen Time / Digital Wellbeing blocks the official apps and stray browsers, leaving the clean app as the only door. Setup step in onboarding + playbook page — zero custom code.

ring 3 · human

Accountability passcode

The OS-lock passcode is held by a trusted person — parent, spouse, friend. The structure serious recovery uses.

03

How it stays alive — the watcher loop

Platforms rewrite their pages constantly; this is the treadmill that kills solo projects. Answer: AI runs the treadmill, a human holds the gate, the community amplifies. Owner approved; modest hosting/API cost accepted.

⏰

Scheduled check

Weekly/daily job loads each platform

🔍

Detect breakage

Tests every rule against the live page

✍️

AI drafts fix

New selector from the changed HTML

👤

Human gate

One-tap approve by the owner — never auto-ship

🚀

Rules ship

Everyone updated, no app release

Community fixes later merge into the same review queue. A wrong selector that hides the player is worse than a missed Shorts shelf — hence the gate.
